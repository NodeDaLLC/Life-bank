# 🏦 Game of Life Digital Bank

A modern, responsive web application for managing finances in your Game of Life board game. Track up to 4 players with their colored vehicles and manage loans and transactions easily.

## 🎮 Features

### Players
- **Blue Vehicle** - Track finances for the blue player
- **Green Vehicle** - Track finances for the green player  
- **Pink Vehicle** - Track finances for the pink player
- **Yellow Vehicle** - Track finances for the yellow player

### Quick Loans
- $10,000 loans
- $50,000 loans (as many as you want!)
- $100,000 loans
- $500,000 loans

### Custom Transactions
- Add custom amounts to any player
- Remove custom amounts from any player
- Add descriptions for each transaction
- Real-time balance updates

### Transaction History
- Complete transaction log with timestamps
- Color-coded by player
- Ability to delete/reverse transactions
- Positive/negative amount indicators

## 🚀 How to Use

1. **Open the app**: Simply open `index.html` in any modern web browser
2. **Quick Loans**: 
   - Select a player from the dropdown
   - Click any loan amount button ($10k, $50k, $100k, $500k)
3. **Custom Transactions**:
   - Select a player
   - Enter an amount
   - Add a description (optional)
   - Click "Add Money" or "Remove Money"
4. **View History**: All transactions appear in the transaction history section
5. **Delete Transactions**: Click the trash icon to reverse any transaction

## 🎨 Design Features

- **Pure HTML/CSS/JavaScript**: No external dependencies
- **Local Storage**: All data is stored in your browser
- **Cross-platform**: Works on any device with a modern browser
